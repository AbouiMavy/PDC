# Développement collaboratif du portail PDC

## Organisation
- La branche main contient la version officielle.
- Chaque développeur travaille sur une branche distincte.
- Toute modification est soumise par Pull Request.
- La fusion dans main nécessite une validation.

## Contrôles
- Vérifier le fonctionnement du projet.
- Exécuter npm run build.
- Ne jamais publier de clés secrètes ou de fichiers .env.
